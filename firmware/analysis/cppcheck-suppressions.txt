# false positives unless the whole program is analyzed. Even with the full
# idf.py compile_commands.json, the following remain invisible to cppcheck's
# call-graph:

#  - FreeRTOS task entry points (*_task) invoked by the RTOS scheduler via
#    xTaskCreate (function-pointer registration cppcheck cannot trace),
#  - BLE/host-stack callbacks registered via function pointer.
# None are genuinely dead. Retained until cppcheck can trace RTOS/ESP-IDF
# indirect calls (tracked as a long-term tooling follow-up).
