## Screenshot Guidelines

- Use the dark theme (default)
- Show realistic data (connected state with telemetry flowing)
- Include the connection badge showing "Verbunden" (Connected)
- For CarPlay screenshots, show music metadata with album art placeholder
- For controller screenshots, show the button mapping with active highlights
- App icon must not appear in screenshots
- Status bar should show realistic time and signal

## App Icon

- **Size:** 1024x1024 px
- **Format:** PNG (no transparency for App Store)
- **Content:** Transalp Bordcomputer logo on dark background
- **Safe area:** Keep important content within the center 80%

## App Preview Video (Optional)

- **Duration:** 15-30 seconds
- **Content:** Connection flow → Dashboard with live telemetry → CarPlay control
- **Format:** H.264 MP4, Portrait
